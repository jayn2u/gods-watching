# 추론을 유지하면서 메모리 여유에 따라 학습 허용

내장 CUHK-PEDES 파인튜닝은 카메라 분석과 검색을 유지한 상태에서 실행한다. 학습 설정에 따른 GPU 메모리 추정치와 추론 부하 변동을 위한 여유분을 현재 가용 메모리와 비교하고, 실행 직전에 서버에서 재확인하여 부족하면 시작을 거절하고 팝업으로 이유를 알린다. 이는 학습 동안 추론을 일시 중지하는 대안 대신 서비스 연속성을 선택한 결정이다.

메모리 추정 통과는 이후의 메모리 확보를 보장하지 않는다. 실행 중 OOM이 발생하면 학습을 실패 처리하고 GPU 메모리를 해제하며, 저장된 checkpoint를 보존하고 더 작은 batch size로 재실행하도록 안내한다. 선택된 실험 조건을 유지하기 위해 batch size를 자동 변경하지 않는다.

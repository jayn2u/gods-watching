# 실행 저장소의 학습 이력을 읽기 전용으로 조회

작업 상태와 실행 소유권은 PostgreSQL에 저장하고, epoch metric과 로그의 권위 사본은 승인된 설계대로 실행 저장소의 JSONL 파일로 유지한다. API는 인증된 typed 조회를 위해 이 저장소를 read-only로 mount하고, 학습 서비스만 기록하며 카메라 분석 worker에는 mount하지 않는다. 별도 DB 이력 사본을 추가하는 대신 하나의 기록을 유지해 재개 시 일관성을 보장한다.

학습 프로세스는 DB의 실행 소유권을 확인한 잠금 안에서 제한된 기록을 append한다. 조회는 불완전한 마지막 행을 건너뛰고 cursor를 진행시키지 않으며, 공개 오류와 로그에는 알려진 안전한 메시지만 남긴다.
